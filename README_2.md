# TASECA Landing Page

Landing page minimalista y futurista para **TASECA** — The All-Seeing Eye Consulting Analytics.

## 🎨 Características

- Diseño **neon/cyberpunk** con tema oscuro
- Fully responsive (mobile-first)
- Efectos hover animados por canal
- Enlaces directos a: Página web, WhatsApp, Instagram, TikTok
- Tipografía premium: Orbitron, Barlow Condensed, JetBrains Mono
- Paleta de colores vibrante: oro (#ffd23f), cian (#35e8d6), púrpura (#8c6eff), verde (#2ee86f)

## 🚀 Quick Start

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/tu-usuario/taseca-landing.git
   cd taseca-landing
   ```

2. **Abrir en el navegador:**
   - Abre `index.html` directamente en tu navegador
   - O sirve con un servidor local:
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Python 2
   python -m SimpleHTTPServer 8000
   
   # Node.js
   npx http-server
   ```

3. **Acceder:**
   - http://localhost:8000

## ✨ Personalización

### Colores
Modifica en `index.html` las siguientes variables:
- `#ffd23f` - Oro/Amarillo
- `#35e8d6` - Cian
- `#8c6eff` - Púrpura
- `#2ee86f` - Verde

### Textos
- Línea 48: Logo "TASECA"
- Línea 49: Tagline "Tu negocio, bajo control"
- Línea 75-76: "Página Web" + URL
- Línea 86-87: "WhatsApp" + mensaje
- Línea 100-101: "Instagram" + usuario
- Línea 111-112: "TikTok" + usuario

### Imágenes
Reemplaza los archivos en `assets/`:
- `taseca-mark.png` - Logo (recomendado 116x116px)
- Otros iconos según tamaños especificados
