## 🎨 Guía de Diseño

**Paleta de Colores TASECA**:
- 🟨 Oro: `#ffd23f`
- 🟦 Cian: `#35e8d6`
- 🟪 Púrpura: `#8c6eff`
- 🟩 Verde: `#2ee86f`

**Estilo**: Neon/Cyberpunk
- Bordes definidos
- Glow/Luz de neón
- Fondo oscuro/transparente
- Alta saturación de colores

## 📝 Notas

- Todos los PNG deben tener **fondo transparente**
- Los tamaños especificados son recomendados pero flexibles
- Si usas formatos SVG, actualiza el HTML para `<img src="...svg">`
- Para iconos simples, considera usar SVG inline en el HTML

## 🔗 Herramientas Recomendadas

- **Diseño**: Figma, Adobe XD, Illustrator
- **Edición**: Photoshop, GIMP, Affinity Photo
- **Conversión**: TinyPNG, ImageOptim
- **SVG**: Inkscape
